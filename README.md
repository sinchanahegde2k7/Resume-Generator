# 🎓 AI Resume Generator for Students

A web-based AI-powered resume generator built with Python & Flask.
Students fill in their details and receive a professional PDF resume instantly!

## ✨ Features
- Beautiful web form interface
- AI-generated professional resume content
- Instant PDF download
- Clean two-column resume layout

## 🛠️ Built With
- Python & Flask (Web Server)
- Groq AI — LLaMA 3.1 (Content Generation)
- ReportLab (PDF Creation)
- HTML & CSS (Frontend)
